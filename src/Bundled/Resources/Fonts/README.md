# Fonts

A `.ttf` or `.otf` file is a `Font`. The font loader draws its characters once into an atlas, at the pixel size set in
its `.meta`. The font loader's import settings type documents the keys, and the `.meta` files here are examples.

To use the same font at another size, copy the file and give the copy its own `.meta`.

A font the engine ships keeps its licence in a text file next to it.
